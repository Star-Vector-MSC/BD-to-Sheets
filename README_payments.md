# История платежей WB

`export_payments.py` читает `public.wb_payment_history` только на чтение и заменяет A:H явно заданного листа. Полный снимок содержит заголовки и не добавляет дубли. Название листа, gid и заголовки проверяются; при сокращении очищается только устаревший хвост A:H. Другие листы не меняются.

```powershell
.\.venv\Scripts\python.exe -B export_payments.py --config PATH_TO_EXISTING_ENV --spreadsheet SPREADSHEET_ID --gid SHEET_GID --sheet SHEET_TITLE
```

Параметры передаются локально; файл env и Google-ключ не публикуются. Относительный путь GOOGLE_APPLICATION_CREDENTIALS считается от каталога файла env.

Идентификаторы сохраняются текстом, суммы — числами, даты переводятся в Europe/Moscow и отображаются как ДД.ММ.ГГГГ. `payment_completed_at` — `payload.updateDT`, `updated_at` — `updated_at_db`. После записи перечитывается и сравнивается вся выгрузка.

В существующей установке настроена задача `WB Payments to Google Sheets - Daily 10 MSK`, ежедневно в 10:00 МСК. Она использует ранее настроенное окружение и внешний файл credentials; добавление почасовых заказов её не изменяет. Компьютер должен быть включён и пользователь войти в Windows. Пропущенный запуск выполняется при доступности, разрешено пробуждение, три повтора через 10 минут; параллельные экземпляры запрещены.

Локальные `runs/payments.log`, `payments-last-success.json`, `payments-previous.json` исключены из Git. Успех записывается только после сверки всех значений. Публикация скрипта не создаёт новое расписание платежей на другом компьютере.
