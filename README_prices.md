# Разовое обновление плановых цен

Заголовки находятся в строке 4: `wild` сопоставляется с `article.local_vendor_code`, `цена продажная плановая` — с последней `wb_order_feed.seller_price` по `created_at`. При одинаковом времени SQL не задаёт дополнительного критерия выбора.

Укажите локально параметры из `.env.example`: PGHOST/PGPORT/PGUSER/PGPASSWORD/PGDATABASE, путь Google-ключа, PRICES_SPREADSHEET_ID, PRICES_SHEET_GID и PRICES_SHEET_NAME. Можно передать внешний файл credentials через `--config`. Для существующей установки прежние частные параметры вынесены в `prices.local.env`, исключённый из Git; он также может содержать путь CREDENTIALS_ENV_FILE к существующему env. Приоритет — уже установленные переменные окружения, затем `prices.local.env`, затем внешний env. `--key` явно задаёт путь Google-ключа.

```powershell
.\.venv\Scripts\python.exe -B update_prices.py --config PATH_TO_EXISTING_ENV
.\.venv\Scripts\python.exe -B update_prices.py --config PATH_TO_EXISTING_ENV --apply
```

Первый запуск — только предпросмотр. Второй требует ввода `UPDATE` после просмотра изменений. Автоматическое расписание цен не создаётся.

Изменяются только отдельные ячейки целевого столбца, оформление сохраняется. Пустые артикулы, отсутствующие цены, SQL NULL и формулы пропускаются; нулевая цена записывается. Прежние и новые значения сохраняются в локальном CSV в `runs/`. Перед записью проверяется неизменность листа, после — все изменённые цены. Не редактируйте и не сортируйте лист во время запуска.
